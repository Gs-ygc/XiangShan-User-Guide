## 矩阵访存通路

* 矩阵请求经专用响应通路返回；
* 命中读：本地命中后经专用旁路直接回传；
* 未命中读：下发一致性读请求，返回后更新本地缓存行并回传；
* 写后读冲突：RAW 旁路直接推送流水线内最新数据；
* 写请求：写直达，需等待写授权应答。

## 操作数内存约束

* 矩阵操作数缓冲必须位于**物理连续内存池**（`/dev/mem` @ `0x100000000`）；
* AMU 按 `PA_base + row × stride` 计算行地址，**不逐行重新查 TLB**，因此非连续缓冲在行数较大时（如 63 行、127 行以上）会静默读错，而不是报错；
* 分配模式（池模式 / 匿名模式）必须由外部环境决定，不能编进产物：匿名模式只用于 QEMU 用户态，若被无条件带上板，表现为 `SIGABRT`（`rc=134`）或匿名池下算错被门禁拦截（`rc=255`）。

## 可见性与内存序

* 矩阵访存与其他访存之间的顺序约束由同步指令与 CSR 语义给出；
* 与标量/向量之间的同步统一使用 `mfence`；
* `mrelease` / `macquire` 必须覆盖所有退出分支，否则会出现偶发错（非稳定复现）；
* 缺少同步时的行为未定义。

## 已知限制

* 裁剪配置下的行为与性能差异；
* 历史上软件默认保证矩阵 load/store 命中 L2（早期缺陷的规避写法），因此常规测试路径不会触发 miss 通路，miss 相关统计长期为异常值。评估 miss 性能前，应先在裸机小用例上验证 miss 通路本身是否正确。
