## 矩阵访存通路

* 矩阵请求经专用响应通路返回；
* 命中读：本地命中后经专用旁路直接回传；
* 未命中读：下发一致性读请求，返回后更新本地缓存行并回传；
* 写后读冲突：RAW 旁路直接推送流水线内最新数据；
* 写请求：写直达，需等待写授权应答。
