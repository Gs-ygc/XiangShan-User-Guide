## 矩阵访存通路

- 矩阵请求走专用响应通路，与普通访存路径的差异
- L2 命中读：Tag 校验命中后经专用旁路直接回传
- L2 未命中读：下发一致性读请求，返回后更新本地缓存行并回传
- RAW 冲突旁路：写后读重叠事务直接推送流水线内最新数据
- 写请求：写直达策略，需要等待写授权应答
