## 挂起与卡死

- 通用卡死看门狗：仅统计完成类里程碑，阈值随已接收命令自适应，超时可输出确定性签名
- 排查顺序：确认是否仍有指令提交 → 检查矩阵完成事件 → 检查访存响应
