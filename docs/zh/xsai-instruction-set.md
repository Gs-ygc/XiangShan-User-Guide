# 指令集扩展 {#sec:xsai-instruction-set}

本章描述香炉峰相对昆明湖 V2R2A 的指令集增量。基线处理器支持的扩展列表见《香山开源处理器用户手册·指令集》。

## 扩展与版本对应

| 扩展 | 说明 | 规范版本 |
| --- | --- | --- |
| ZAMES | 矩阵计算扩展（配置、矩阵乘加、矩阵访存、同步） | proposal-14 及后续 |
| ZMASYNC | ZAMES 的同步伴随扩展（同步寄存器指令） | 同上 |
| 自定义低精度转换 | `vfncvtmxfp.f.f.w`、`vfncvtxx8.f.a.w` 等 | 见《多精度》相关提案 |

## 配置与同步指令

- `msettilem` / `msettilen` / `msettilek`：设置 tile 形状
- `msetcfg` / `mgetcfg`：矩阵配置寄存器读写
- `mzero`：矩阵寄存器清零
- `mrelease` / `macquire`：异步矩阵操作的释放与获取

## 异步执行与顺序语义

- 矩阵指令为异步执行：提交顺序与实际完成顺序可以不同
- 与标量/向量指令之间的顺序由同步指令与 CSR 语义约束
- **对未写入矩阵寄存器区域的读取属未定义行为（UB）**，功能模拟器与差分验证会对越界读写报错
