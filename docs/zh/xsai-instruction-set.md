## 配置与同步

* `msettilem` / `msettilen` / `msettilek`：设置 tile 形状
* `msetcfg` / `mgetcfg`：配置寄存器读写
* `mzero`：矩阵寄存器清零
* `mrelease` / `macquire`：异步矩阵操作的释放与获取

使用约束：

* `macquire` 之前的 MSC 基址寄存器需要钉住（例如 `s11`）并保活，编译器回收该寄存器会导致偶发错；
* 每张 tile 使用前 `msyncregreset`；
* 与标量 / 向量之间的同步统一使用 `mfence`；
* `mrelease` / `macquire` 必须覆盖**所有**退出分支。

## 矩阵乘加

| 指令族 | 输入精度 | 输出精度 | 备注 |
| --- | --- | --- | --- |
| `mmacc` 整数 | i8 × i8、i2 × i8 | i32 | 位宽不对称场景见低精度章节 |
| `mmacc` 浮点 | bf16 × bf16、f16 × f16 | fp32 | 累加器恒为 fp32 |
| 低精度 | fp8 / fp4 系列 | fp32 | 需配合 pack / unpack |

bf16 路径下 `msettilek` 按元素计（`msettilek=32`），而矩阵乘加指令的 N 参数按字节计（对应 64 字节）。bf16 与 int8 的开关必须分开：bf16 改变浮点精度，共用开关会让官方 fp32 测试因容差挂掉。

## 矩阵访存

* 整块与分块加载 / 存储（按 tile 形状）；
* 转置加载 / 存储（行主序访问、stride 控制）；
* 细粒度访存（任意尺寸、8 / 16 / 32 位元素、尾数掩码）；
* 多通道访存与 bank 分配。

约束：

* 操作数缓冲必须物理连续（见[内存子系统与 HBL2](xsai-memory.md#sec:xsai-memory)）；
* 行地址由 `PA_base + row × stride` 给出，不做逐行 TLB 重查；
* 尾包（`real_count < DST_XUNIT`）为紧凑布局，不能沿用固定步长。

## 异步执行与顺序

* 矩阵指令异步执行：提交顺序与完成顺序可以不同；
* 与标量 / 向量指令之间的顺序由同步指令与 CSR 语义约束；
* **读取未写入的矩阵寄存器区域属未定义行为（UB）**，功能模拟器与差分验证会将其变为可检出错误。
