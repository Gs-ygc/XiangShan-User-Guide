# 异常与中断 {#sec:xsai-exception}

本章描述与矩阵扩展相关的异常与中断行为；通用机制见《香山开源处理器用户手册·异常与中断》。

## 新增异常条件

* 非法指令：扩展未使能或配置非法时的矩阵指令；
* 对齐与访存错误：矩阵访存对地址与 stride 的约束；
* 未定义行为：读取未写入的矩阵寄存器区域等，功能模拟器与差分验证会将其变为可检出错误。
