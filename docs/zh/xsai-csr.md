## 规格探针

软件在启用矩阵路径前，应通过 CSR 读取当前 hart / bit 的原生 tile 几何，并只按探针结果生成核。这是接入矩阵单元的第一步，也是唯一可信的规格来源：配置寄存器里的形状参数只在原生几何内才保证正确。

## 精度能力描述

* 不再使用只读位图（`xmisa`）表达矩阵精度能力，改用每个 hart 的设备树属性 `riscv,matrix-isa-caps` 描述输入 / 输出类型组合；
* 动机：位图难以表达"输入 × 输入 → 输出"的组合数量增长。
