## 推荐分析流程

1. 算子级性能表（周期、IPC、有效带宽、算术强度、峰值占比）；
2. HPM 判断瓶颈类型（访存 / 计算 / 调度）；
3. 结构化追踪定位到具体模块与时刻。

## 口径要求

报告中的性能数字必须写清单次调用、per-MAC 还是整网口径，否则数字之间不可比。区分"矩阵单元引入的误差"与"量化 / 截断本身的误差"同样重要：验证适配正确性的判据是矩阵开关开、关下输出位级一致，而不是与某一版量化模型的精度差。
