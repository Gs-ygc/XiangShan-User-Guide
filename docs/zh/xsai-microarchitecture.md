# 微架构增量 {#sec:xsai-microarchitecture}

本章只描述香炉峰在昆明湖 V2R2A 微架构之上新增或修改的部分。

## CUTE 矩阵单元

- 定位：独立的矩阵计算单元，与标量核通过 AMU 控制通路交互
- 内部组成：访存通路（AML/BML/CML）、转置引擎、矩阵乘加通路、acc/tile 寄存器堆

## AMU 控制通路与指令提交

- 核内完成指令解码、必要的整数源寄存器读取与 0 拍写回
- 命令装入 AMU 控制项后由 ROB 按普通指令提交
- 向量运算、向量寄存器读写与 RAW/WAW 依赖留在核外执行单元（EVU）跟踪

## 时钟域

- 香炉峰支持 CUTE 与核心运行在不同时钟域（acceleratorClock）
- 命令、完成通知、矩阵数据、性能统计与 difftest 事件分别经异步 FIFO 跨域
- **保留同频直连模式**，可作为配置项关闭异步逻辑

## HBL2 与外部 LLC

- 支持外部 LLC 后端（ZhuJiang / OpenLLC 等），与矩阵访存通路配合
