# 数据寄存器 {#sec:xsai-registers}

本章描述香炉峰新增的矩阵相关寄存器。标量/向量寄存器与昆明湖 V2R2 一致。

## 矩阵寄存器

| 类型 | 名称 | 用途 |
| --- | --- | --- |
| A / B tile | `tr0` – `tr3` | 矩阵乘加的操作数 |
| C / acc tile | `acc0` – `acc3` | 累加与结果 |

累加器 `acc` 在整数与 bf16 路径下均为 fp32 精度，低精度输入不改变累加器宽度。

## 原生 tile 几何

矩阵单元只实现两套原生几何，软件**必须使用探针读到的规格**：

| 配置 | 原生几何（M × N × K） | 说明 |
| --- | --- | --- |
| default | 128 × 64 × 128 | v13 系列 bit 使用 |
| mini | 64 × 64 × 64 | min-v6 系列 bit 使用 |

规格与 bit 不匹配时结果必然出错；板级整层错、而 QEMU 全对，通常就是这一条。

## 配置寄存器

* `mcfg0` – `mcfg7`：由配置指令访问，描述 tile 形状、数据类型与访存模式。

### 形状与类型参数

* `msettilem` / `msettilen` / `msettilek`：设置 tile 的 M、N、K 维度。
* bf16 路径下 `msettilek` 按**元素**计（`msettilek=32`），而矩阵乘加指令的 N 参数按**字节**计（对应 64 字节）。
* K 维不是 128 的整数倍时需要 padding 或尾数处理。

## 布局与对齐约束

* 操作数缓冲必须位于**物理连续内存池**（`/dev/mem` @ `0x100000000`）：AMU 行寻址按 `PA_base + row × stride` 计算且不逐行重查 TLB，非连续缓冲在行数较大时会静默读错；
* 转置访存有行主序 / 列主序约定，由访存指令的 stride 控制；
* 差分验证 dump 比对时要剔除 16 B 对齐引入的 padding（未初始化内存），只比对有效元素，否则会产生假失败。
