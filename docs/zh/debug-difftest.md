# 差分验证 {#sec:debug-difftest}

## 概述

差分验证（difftest）将香炉峰的执行结果与功能参考模型逐步对比，是矩阵扩展功能正确性的主要保障手段。

## 参考模型

- 支持 CPU 参考模型与 GPU 参考模型两条路径
- 矩阵指令支持 batching、反压与顺序检查
